# DeviceGuard

A dark, modern Windows device manager with real-time monitoring, toast notifications, and security scanning.

> **Work in progress** — this project is under active development.

## Planned Features

- Real-time USB/PnP device connection and disconnection monitoring
- Windows toast notifications on device events
- Windows Defender scan on USB storage connect
- YARA rule-based file scanning on connected drives
- Unsigned driver detection
- Full connection history with CSV export
- System tray integration with alert icons
- One-click installer (Inno Setup)

## Requirements

- Python 3.11+
- Windows 10 or Windows 11
